# Usando Agent Router com Roo Code


## Instalar RooCode no VSCode

1. Procure por [RooCode](https://marketplace.visualstudio.com/items?itemName=RooVeterinaryInc.roo-cline) no VSCode e instale.

2. Visite https://agentrouter.org/console/token para obter sua API Key


## Adicionar Provider

Após concluir a instalação do Roo Code, você pode abrir o Roo Code, selecionar configurar provider e adicionar um provider compatível com OpenAI. Os itens de configuração específicos podem se referir a:


- OpenAI Base URL: `https://agentrouter.org/v1`
- API Key: A chave que você criou em https://agentrouter.org/console/token
- Model: `gpt-5`

Após concluir a configuração, salve e você pode começar a usar.
