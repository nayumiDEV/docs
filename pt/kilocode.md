# Usando Agent Router com Kilo Code


## Instalar Kilo Code no VSCode

1. Procure por [Kilo Code](https://marketplace.visualstudio.com/items?itemName=kilocode.Kilo-Code) no VSCode e instale.

2. Visite https://agentrouter.org/console/token para obter sua API Key


## Adicionar Provider

Após concluir a instalação do Kilo Code, você pode abrir o Kilo Code, selecionar configurar provider e adicionar um provider compatível com OpenAI. Os itens de configuração específicos podem se referir a:


- OpenAI Base URL: `https://agentrouter.org/v1`
- API Key: A chave que você criou em https://agentrouter.org/console/token
- Model: `gpt-5`

Após concluir a configuração, salve e você pode começar a usar.
